# APA TPAC Meeting (and Breakout) planning

This repo is being used to plan APA WG's attendance of TPAC meetings and breakouts.

The planning is done via issues created in a specific format to be used with [tpac-scheduling-helper](https://github.com/matatk/tpac-scheduling-helper).

Here are two key links to help with the planning:

* [TPAC overview and attendance planning page](https://w3c.github.io/apa-tpac-meetings/planning.html) - allows you to semi-automatically file those issues, via a list of all currently-timetabled TPAC events (timetabling of breakouts comes after timetabling of group meetings).

* [Group scheduling page](https://w3c.github.io/apa-tpac-meetings/schedule.html) - highlights meetings that have moved, planned attendances that clash, and provides group members with individual timetables.
